UniQdata 기반 어르신용 앱

Bodab

Bodab은 어르신이 큰 글씨와 짧은 단계로 복약·일정·일상 체크인을 직접 관리하도록 돕는 앱입니다.

어르신이 공유를 허용한 기록은 가족이 UniQdata의 FamilyCare에서 동의 범위 안에서 확인할 수 있습니다.

어떤 일을 할 수 있나요?

  • 큰 글씨와 짧은 안내
  • 복약 일정과 본인 확인
  • 병원 방문 일정
  • 일상 체크인
  • 가족 공유 범위 선택

활용 예시

어르신의 하루를 확인할 때

어르신은 앱에서 복약 일정과 병원 방문 일정을 보고 직접 체크인합니다. 가족은 어르신이 허용한 내용만 FamilyCare에서 확인합니다.

현재 범위

Bodab은 개인이 쓰는 어르신용 앱입니다. 기관의 돌봄 요청·담당자 배정 업무는 Bodab Senior에서 별도로 설명합니다.

개인 통제 · 블록체인 기반 검증

공유의 기준은 개인에게.

Bodab에서 남긴 기록은 어르신이 허용한 범위 안에서 가족과 연결됩니다. 가족 공유와 기관의 돌봄 업무 권한은 구분됩니다.

SportiQue의 공유 아키텍처는 개인의 기록 보관, 동의와 권한, 블록체인 기반 증빙 검증을 분리합니다. 건강기록 원문과 복호화 키를 공개 원장에 올리는 방식이 아닙니다.

  1. 1

    개인이 정하는 범위

    공유 대상·목적·기록 범위를 동의에 연결합니다.

  2. 2

    권한에 맞춘 전달

    수신자의 권한과 키를 확인하고, 허용된 범위의 암호화 전달을 연결하는 설계입니다.

  3. 3

    원문과 분리된 증빙

    동의·접근·공유 이력의 증빙을 배치로 묶고, 원문을 공개하지 않는 블록체인 검증 구조에 연결합니다.

  4. 4

    철회와 이력 확인

    새로운 접근을 차단하는 철회와, 이미 남은 이력의 증빙 확인을 구분합니다.
